# 💻 Computadores para Inclusão

Um projeto web educativo sobre inclusão digital, recondicionamento de computadores e impacto social.

## 📋 Sobre o Projeto

O **Computadores para Inclusão** é um projeto desenvolvido para apresentar como o reaproveitamento de equipamentos de informática pode contribuir para ampliar o acesso à tecnologia.

O site aborda a importância da inclusão digital e apresenta informações sobre o recondicionamento de computadores e seus possíveis benefícios para a sociedade.

## 🎯 Objetivos

* Explicar a importância da inclusão digital.
* Apresentar o conceito de recondicionamento de computadores.
* Destacar os benefícios sociais do acesso à tecnologia.
* Demonstrar como iniciativas de inclusão digital podem ampliar oportunidades.

## 🚀 Conteúdo do Site

* **Página inicial (`index.html`):** apresentação do tema.
* **Recondicionamento (`recondicionamento.html`):** conteúdo sobre a recuperação e reutilização de computadores.
* **Inclusão digital (`inclusao.html`):** informações sobre o acesso à tecnologia.
* **Impacto social (`impacto.html`):** abordagem dos benefícios sociais relacionados ao tema.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** estrutura das páginas.
* **CSS3:** estilização e organização visual.
* **Imagens:** apoio visual ao conteúdo.
