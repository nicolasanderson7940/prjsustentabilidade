RECONDICIONAMENTO

Uma nova função para a tecnologia.

Recuperar computadores que ainda podem ser utilizados é uma forma de ampliar o acesso à informática e criar novas possibilidades.

COMO FUNCIONA?

Do computador preparado até uma nova oportunidade.

01

Avaliação

O equipamento é analisado para verificar suas condições e identificar o que precisa ser ajustado.

02

Manutenção

São realizados procedimentos de manutenção e ajustes para preparar o computador para seu novo uso.

03

Testes

O computador passa por testes para verificar se suas funções estão funcionando corretamente.

04

Preparação

O equipamento é preparado de acordo com as necessidades de quem irá utilizá-lo.

05

Doação

Depois de preparado, o computador pode ser direcionado para estudantes, famílias ou projetos comunitários.

06

Oportunidade

O acesso à tecnologia pode contribuir para aprendizado, desenvolvimento e novas oportunidades.

Recondicionar um computador também pode significar criar uma nova oportunidade.
